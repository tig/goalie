# AGENTS.md

guidance/agents.md is canonical. Do not edit this file by hand.

Scope: agents in this repo. No role briefs. Do not look for `agent-harness/briefs/`. Seats are Mike (tig/mike), not enabled here. Issues hold the work. Session start is this file only. SPEC.md for product work. USERS_MANUAL.md for manual work.

The folder is the component. `server/`, `tests/`, and `guidance/` each have a workflow of that name. A change in one component must not run another component's CI. Each workflow starts on every pull request so its check can report. Its commands run only when that component's inputs changed. A component's tests sit with its code. Root `tests/` is only for shared tests and shared test infrastructure. Commands are in CONTRIBUTING.md. Do not invent a setup step.

Every byte here is paid every run. Behavior lives here. SPEC.md is the contract. USERS_MANUAL.md is the manual. No nested AGENTS.md.

Writing: STE, short sentences, stable terms, must / must not, no em-dashes, one line per paragraph and list item, no hard-wrap. Do not reformat a file you are not changing. No formatter. When one arrives, use only that, never on a directory.

SPEC.md is the source of truth. Fix a wrong spec in the same change.

On a principle collision, pick what cuts future cost here. Refactor to the principle first, then change behavior. Constraints, not slogans. Violate one when judgment says so.

Separation of Concerns. One kind of work per part. Root principle.
Encapsulation / Information Hiding. Small stable contract; hide internals.
High Cohesion + Loose Coupling. Change-together stays together; independents talk narrow.
DRY. One home per piece of knowledge, not per similar line. Avoid over-DRY.
KISS. Simplest design that works.
Single Responsibility. One reason to change.
Depend on Abstractions. Policy does not depend on details; both depend on contracts.
YAGNI. Nothing speculative.
Composition over Inheritance. Assemble; do not grow hierarchies.
Open/Closed (with discipline). Extend at stable boundaries, only after the change shows up twice.
Law of Demeter. Fail fast. Illegal states unrepresentable. Optimize for deletion. Do one thing and compose.
